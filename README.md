# FinanceResearchAgent
### Financial Research Assistant | Python · Pandas · Financial Analysis

FinanceResearchAgent is a finance and data analytics portfolio project focused on developing a Python-based assistant for company financial research. It aims to retrieve relevant information from public sources, analyze financial data, validate findings, and generate structured research reports with source references and clearly stated limitations.

## Project Objective

The objective is to build a reproducible financial research workflow that accepts a company research question, identifies relevant evidence, analyzes financial metrics, and prepares a structured report to support further research.

## Initial Research Case

**Company:** Reliance Industries Limited (RIL)  
**Research Source:** Integrated Annual Report FY 2025–26

The initial research covers:

- Company and business overview
- Financial performance and key financial ratios
- Year-over-year financial-ratio movements
- Industry trends and business risks
- Valuation indicators, where reliable data is available
- Source evidence, validation results, and data limitations

## Current Development Status

The project has progressed through initial setup and financial research prototyping.

Work completed or explored includes:

- Setting up the project environment and research source register
- Loading and extracting text from the RIL Integrated Annual Report FY 2025–26
- Building Python-based evidence retrieval for financial research questions
- Extracting and organizing selected financial-ratio evidence
- Comparing FY 2024–25 and FY 2025–26 financial ratios
- Calculating percentage changes and identifying increases or decreases
- Testing evidence retrieval and identifying questions requiring further review

**Important:** This is an evolving prototype. Full LLM integration, comprehensive financial-data retrieval, complete source validation, and end-to-end automated report generation remain under development.

## Responsible Use

This project is intended for educational, research, and portfolio purposes. Extracted financial information and generated summaries may contain errors and should be checked against the original sources.

Unverified findings, missing information, and limitations should be identified explicitly. This project does not provide personalized investment advice or guarantee investment outcomes.
